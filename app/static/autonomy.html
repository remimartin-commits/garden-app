Getting to code quickly: Topic Start needs OPENAI_API_KEY (or FEATURE_SCHEMA_OPENAI_API_KEY) for schema draft/finalize. Optional Claude audit uses ANTHROPIC_API_KEY (same names as in Anthropic’s docs; aliases CLAUDE_API_KEY / ANTHROPIC_AUTH_TOKEN / FEATURE_SCHEMA_ANTHROPIC_API_KEY also work). Check env_anthropic_configured in Status after Refresh — if false, the server process is not reading your key (wrong name, or restart after editing .env). Without an Anthropic key, the server skips the audit step and still writes a schema JSON. To skip generation entirely, paste an existing path under data/user/feature_schemas/ and leave Topic blank.
Reset clears run state only; it does not delete files under data/user/feature_schemas/. Paste a path from that folder to bind the same schema again.
